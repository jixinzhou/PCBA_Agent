## 数据来源原则

- 四张图片路径均来自AOI test split；少锡图片按用户确认以当前实际文件哈希重新冻结。
- SPI参数均来自 `DOE焊膏印刷实验数据.xlsx` 的真实行，且同时记录实测VTE和正式模型预测VTE。
- 图片和工艺行不是同一生产事件，只构成受控组合样本，不能用于宣称图片缺陷的唯一真实根因。
- 问题由冻结RAG评测题改写为现场问法，原始题号已保存在JSON。

少锡旧test split的22个路径存在当前文件哈希与旧CSV记录错位。该问题表示旧记录不能继续充当当前文件的完整性依据，不表示图片不可运行。本版保留历史哈希用于追溯，并以 `insufficient (86).png` 当前实际SHA256重新冻结T15输入。

## 回流异常样本

C04不再使用69组实验数据，也不再使用PWI 102.29的单因素注入。它复用T14已经验收的 `domain_min_fast` 受控样本：

- 13温区为 `[135,145,155,165,173,180,190,210,220,230,245,260,255]` ℃，链速95 cm/min。
- 测点匹配TC7/U22，输入位于正式训练域内。
- 初始预测PWI为105.46，不合格。
- T14历史闭环中优化后PWI为24.23，独立复验合格。

T14结果只证明该样本能够完成闭环；正式T15评测必须重新调用预测、优化和复验Tool，不能直接复用历史结果。

## 已确认边界

1. VTE用于解释少锡和多锡：`VTE<100`支持少锡候选，`VTE>100`支持多锡候选。
2. C04使用T14已验证的PWI 105.46异常样本，不使用69组实验行。
3. C01按当前实际图片哈希重新冻结。
4. 首轮范围为6个Case加1个复用C04的Tool失败变体。
