# PCBA 跨工序质量诊断智能体

## 1. 项目目标

构建一个 PCBA 跨工序质量诊断智能体，将缺陷识别、RAG 知识检索、缺陷致因知识图谱、工艺预测模型和参数优化模型进行统一编排。

系统完成以下诊断闭环：

```text
用户问题 / 缺陷图片
        ↓
缺陷识别
        ↓
检索相关工艺知识
        ↓
生成候选致因
        ↓
调用工艺预测模型验证
        ↓
调用参数优化模型
        ↓
验证优化结果
        ↓
生成诊断报告
```

系统输出的是**候选原因及其证据支持程度**，不直接声明唯一真实根因。

---

## 2. 系统组成

### 缺陷识别

根据 PCBA 焊点图片识别缺陷类型和置信度。

### RAG

从工艺标准、技术资料和工业文档中检索与当前缺陷相关的原文证据。

### 缺陷致因知识图谱

组织以下关系：

```text
缺陷
→ 候选原因
→ 所属工序
→ 验证指标
→ 验证工具
→ 调整动作
→ 工艺参数
```

### 工艺模型

通过预测模型判断当前工艺状态，通过优化模型搜索推荐参数。

### Agent

负责理解用户问题、查询知识、选择工具、调用工具、组合结果并生成最终诊断报告。

---

## 3. 核心工具

系统包含五个核心 Tool：

```text
pcba_defect_classification
spi_vte_prediction
spi_parameter_optimization
reflow_profile_prediction
reflow_parameter_optimization
```

所有模型能力统一采用：

```text
模型
→ FastAPI
→ Agent Tool
→ Agent
```

的方式调用。

---

## 4. 工序范围

项目主要覆盖：

```text
焊膏印刷
元器件贴装
回流焊
```

其中印刷和回流焊具备预测与优化能力。

贴片工序主要通过知识图谱提供候选原因和人工检查建议。

---

## 5. Agent 诊断逻辑

Agent 根据：

```text
缺陷类型
+
用户问题
+
知识证据
+
候选致因路径
+
已有工艺数据
+
可用 Tool
```

动态决定需要调用哪些工具。

完整逻辑为：

```text
理解问题
→ 识别缺陷
→ RAG 检索
→ 查询知识图谱
→ 生成候选原因
→ 选择预测 Tool
→ 验证工艺状态
→ 判断是否需要优化
→ 调用优化 Tool
→ 再次预测验证
→ 生成报告
```

---

## 6. 最终诊断报告

最终报告至少包含：

* 缺陷识别结果；
* 候选原因；
* 工艺知识证据；
* 工艺模型验证结果；
* 候选原因支持程度；
* 参数调整建议；
* 优化前后结果；
* 未验证因素；
* Tool 调用记录；
* 系统限制说明。

---

## 7. 项目原则

1. RAG 负责寻找知识证据。
2. 知识图谱负责组织致因关系。
3. 预测模型负责验证工艺状态。
4. 优化模型负责寻找推荐参数。
5. Agent 负责工具选择和流程编排。
6. 预测与优化分离，优化后必须重新预测验证。
7. 模型能力通过统一 API 和 Tool 提供。
8. 所有诊断结论必须保留证据和可追溯信息。
9. 不将候选致因描述为已经确认的唯一真实根因。
